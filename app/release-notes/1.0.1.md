**DesktopDiag 1.0.1** · 🇫🇷 Français plus bas

### 🇬🇧 English

Fixes an antivirus false positive: one Windows Defender reported version 1.0 as `Trojan:Win32/Sabsik.EN.B!ml`, a machine-learning guess triggered by how the app ran its checks.

- The checks now run **inside the app**, with the PowerShell engine built into Windows: no more `powershell.exe -ExecutionPolicy Bypass`, no hidden windows, no encoded commands. Nothing on your PC's security settings is touched.
- The **deep scan** asks Windows for administrator permission **in DesktopDiag's name**, only when you tick it.
- **Publisher details** in the file (Lykroze, version, MIT license).
- **Updates are checked at every launch** (can be turned off in settings).

Already on 1.0? The app will offer this update by itself.

### 🇫🇷 Français

Corrige un faux positif d'antivirus : un Windows Defender a signalé la version 1.0 comme `Trojan:Win32/Sabsik.EN.B!ml`, une supposition de son intelligence artificielle, provoquée par la façon dont l'appli lançait ses contrôles.

- Les contrôles tournent maintenant **dans l'appli elle-même**, avec le moteur PowerShell intégré à Windows : plus de `powershell.exe -ExecutionPolicy Bypass`, plus de fenêtres cachées, plus de commandes encodées. Aucun réglage de sécurité de ton PC n'est modifié.
- L'**analyse approfondie** demande l'autorisation administrateur à Windows **au nom de DesktopDiag**, seulement si tu la coches.
- **Informations sur l'éditeur** dans le fichier (Lykroze, version, licence MIT).
- **Les mises à jour sont vérifiées à chaque lancement** (désactivable dans les réglages).

Tu as déjà la 1.0 ? L'appli te proposera cette mise à jour toute seule.
