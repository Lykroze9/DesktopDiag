**DesktopDiag 1.0.0, the Windows app: no Claude needed.** · 🇫🇷 Français plus bas

### 🇬🇧 English

A single portable file (`DesktopDiag.exe`, about 1 MB, nothing to install) that checks your Windows PC and explains in plain words what's wrong and what to do. **Read-only**: it changes nothing, needs no account and sends no data.

- One-click check, score out of 100, every area marked OK / Check / Urgent
- Advice in 3 parts (what it is, why it matters, how to do it), **Open it for me** buttons, **Done** tracking verified at the next check
- Optional **deep scan** with admin rights: SSD health (SMART), blue screen analysis with the likely culprit driver, real startup time, file system check
- Symptom mode, score history, compare two checks, PDF, copy for a forum, technician view
- 4 themes (system, light, dark, high contrast), text size, English or French
- Automatic updates from this page (once a day, can be turned off), verified with SHA-256

**First launch:** the app is not code-signed yet. If Windows SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.
Requires Windows 10 22H2 or 11 (x64) with the Microsoft Edge WebView2 runtime (already there on Windows 11 and up-to-date Windows 10).

### 🇫🇷 Français

Un seul fichier portable (`DesktopDiag.exe`, environ 1 Mo, rien à installer) qui vérifie ton PC Windows et explique simplement ce qui ne va pas et quoi faire. **Lecture seule** : rien n'est modifié, pas de compte, aucune donnée envoyée.

- Check en un clic, note sur 100, chaque domaine marqué OK / À voir / Urgent
- Conseils en 3 parties (ce que c'est, pourquoi c'est important, comment faire), boutons **Ouvrir pour moi**, suivi **C'est fait** vérifié au check suivant
- **Analyse approfondie** en option avec les droits admin : santé des SSD (SMART), analyse des écrans bleus avec le pilote en cause probable, durée réelle du démarrage, vérification du disque
- Mode symptôme, courbe de la note, comparaison de deux checks, PDF, copie pour un forum, vue technicien
- 4 thèmes (système, clair, sombre, contrasté), taille du texte, français ou anglais
- Mises à jour automatiques depuis cette page (une fois par jour, désactivable), vérifiées par SHA-256

**Premier lancement :** l'appli n'est pas encore signée. Si Windows SmartScreen affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis **Exécuter quand même**.
Il faut Windows 10 22H2 ou 11 (x64) avec le composant Microsoft Edge WebView2 (déjà présent sur Windows 11 et les Windows 10 à jour).
